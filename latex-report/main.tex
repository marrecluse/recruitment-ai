% ── Abstract ─────────────────────────────────────────────────
\begin{abstract}
\addcontentsline{toc}{chapter}{Abstract}
The growing volume of digital job applications has created a significant research challenge in computational recruitment: how can Natural Language Processing (NLP) techniques accurately extract, interpret, and semantically match the unstructured content of resume documents against structured job requirements? This project investigates and compares NLP-based approaches to automated resume screening and candidate-job matching, implemented within a full-stack MERN web application that serves as the evaluation environment.

The system comprises four integrated components: an NLP resume parsing pipeline using Named Entity Recognition (NER) with rule-based, spaCy, and BERT-based approaches; an intelligent job matching algorithm comparing TF-IDF cosine similarity, Sentence-BERT embeddings, and BERT binary classification; a secure RESTful backend API built with Node.js, Express, and MongoDB with GDPR compliance and asynchronous job queuing; and a React-based frontend providing transparent, accessible presentation of AI-generated match scores and skill-gap analyses.

The project addresses a documented gap in the literature: the absence of open, reproducible evaluations of NLP recruitment pipelines across diverse, multi-format datasets with documented bias assessments. Results contribute a benchmark comparison of NER and semantic matching approaches, a bias audit of algorithmic candidate rankings, and a user-centred interface design for transparent AI-assisted recruitment decisions.
\end{abstract}
